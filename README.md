# Turbo Chat com Rails 8

O que foi usado:
- Hotwire Turbo
- SQLite3
- Tailwind
- Webpack

Passo a passo:
- Instale o Ruby 3.4.2
- Rode o comando bundle install e yarn install
- Rode o setup do banco de dados
- Inicie a aplicação em desenvolvimento com bin/dev
- Pronto
